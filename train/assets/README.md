# Ассеты «Узловой» — пиксель-арт для Godot

Всё нарисовано с нуля кодом, никаких чужих паков. Бери и используй как хочешь.
Папки `1x/`, `2x/`, `3x/` — одни и те же картинки в масштабе ×1, ×2, ×3 (без размытия).
Базовый тайл — **16 px**, персонаж — **16×32**, как в том паке со скрина.

Перегенерить всё: `node tools/build.mjs` из папки `train/assets`. Node и всё, ничего ставить не надо.

## Что внутри

### Пассажиры — `passengers_<город>.png`
Лист как в RPG Maker: **8 персонажей, 4×2**, каждый блок **48×128**.
Внутри блока: **3 кадра ходьбы** по горизонтали × **4 направления** по вертикали.

| строка | направление |
|---|---|
| 0 | вниз (лицом к игроку) |
| 1 | влево |
| 2 | вправо |
| 3 | вверх (спиной) |

Столбцы: **0 — шаг, 1 — стоит, 2 — шаг другой ногой.** Для анимации ходьбы гоняй `0,1,2,1`.

Восемь файлов — по цвету одежды, то есть по городу назначения:
`berezovka` (оранжевый), `seversk` (синий), `ozersk` (зелёный), `kamenka` (фиолетовый),
`yasnoe` (красный), `prirechye` (розовый), `zavodskoy` (серый), `domoy` (светло-серый, едут домой).
Внутри каждого файла 8 разных людей: три причёски (короткая, длинная, кепка), четыре тона кожи,
разные волосы и штаны. Итого **64 персонажа**.

### Поезд — `train_<цвет>.png` (264×52)
Три спрайта в ряд, носом вправо:

| x | что | размер |
|---|---|---|
| 0 | вагон, двери закрыты | 96×52 |
| 100 | вагон, двери открыты | 96×52 |
| 200 | локомотив | 64×52 |

Центр колёс — **y = 44**, по нему выставляй поезд на рельс. Дверь вагона — около **x = 48**.
Цвета: `red`, `blue`, `green`, `yellow`.

### Салон в разрезе — `salon_<цвет>_back.png` / `_front.png` (160×96)
Один вагон изнутри: потолок с лампами, багажная полка, окна, дальний ряд сидений,
проход, ближний ряд спинками к нам.

**Рисовать в три слоя:** `salon_*_back` → спрайты пассажиров → `salon_*_front`.
Тогда сидящие оказываются в кресле, а стоячие — в проходе перед ближними сиденьями.
Координаты посадки лежат в `anchors.json`:

- **4 сидячих места**: x = 12, 52, 92, 132, y = 30 (кадр `down`, столбец 1)
- **5 мест стоя**: x = 26, 52, 78, 104, 130, y = 46 (любой кадр, лучше `left`/`right`)

`salon_*_back_night.png` — то же, но за окном ночь и огни. `salon_demo.png` — как это выглядит
собранным: сверху набитый вагон, снизу полупустой.

## Как подключить в Godot 4

**Один раз на проект** — чтобы пиксели не мылились:
Project Settings → Rendering → Textures → Canvas Textures → **Default Texture Filter = Nearest**.
(Или на каждой текстуре в импорте: Filter — off, Mipmaps — off, и Reimport.)

Бери файлы из `1x/` и масштабируй камерой/`scale`. Класть `2x`/`3x` в проект имеет смысл,
только если не хочешь возиться с масштабом.

**Пассажир.** `AnimatedSprite2D` → SpriteFrames → Add frames from Sprite Sheet,
размер кадра 16×32, выбери нужную строку. Или `Sprite2D` + `AtlasTexture` и двигай `region`:
```gdscript
# кадр ходьбы: dir 0..3 (вниз, влево, вправо, вверх), step 0..3 → кадры 0,1,2,1
var frames := [0, 1, 2, 1]
atlas.region = Rect2(frames[step] * 16, dir * 32, 16, 32)
```

**Тайлсет.** TileSet → Add Atlas → `station_tiles.png`, Texture Region Size 16×16,
Automatically Create Tiles. Нумерация клеток — как в списке выше (слева направо, сверху вниз).

**Салон.** Три узла по порядку: `Sprite2D (back)`, `Node2D (пассажиры)`, `Sprite2D (front)`.
Якоря из `anchors.json` — это левый верхний угол спрайта пассажира 16×32.

## Поменять цвета или добавить город

Всё живёт в `tools/build.mjs`:

- `CITY` — цвета одежды по городам (добавь строчку — получишь новый лист пассажиров),
- `TRAINS` — цвета поездов,
- `SKINS`, `HAIRS`, `PANTS`, `CAPS`, `STYLES` — из чего собираются восемь разных людей,
- `P` — общая палитра мира (перрон, кирпич, трава, стекло).

Сама графика — в `tools/people.mjs` (люди нарисованы ASCII-картинками, буква = цвет из палитры)
и в `tools/build.mjs` (поезд, тайлы, предметы). `tools/pixel.mjs` — холст, обводка, масштаб и PNG.
Обводка вокруг силуэта ставится автоматически, руками её рисовать не надо.
