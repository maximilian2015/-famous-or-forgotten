## Самое важное — одно

**Проследи, чтобы изменённые файлы попали обратно в `extracted\src\`.**

Это единственное, что может сломаться. Опасный сценарий: ChatGPT выдаёт код
текстом в чате, ты копируешь его куда-то ещё или сохраняешь только собранный
`game.html`. Тогда исходники расходятся со сборкой, и дальше работать нельзя —
из собранного файла код обратно не разбирается.

**Как правильно:** проси у него файлы целиком с указанием пути
(например `src/systems/career/agent.js`), клади их ровно туда, и после каждой
задачи прогоняй `node build-singlefile.mjs`. Если сборка прошла — исходники целы.

**Идеально:** после каждой рабочей задачи делай коммит. Тогда я увижу всю историю:

```bash
cd C:\Users\maximilian\Desktop\game && git add -A && git commit -m "что сделали"
```
