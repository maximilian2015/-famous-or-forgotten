## Что за игра: "Famous or Forgotten"

BitLife-подобный симулятор жизни знаменитости. Играешь путь от рождения до
славы (или забвения). Собрана как один HTML-файл (веб, React), запускается
двойным кликом.

**Ядро (концепция, утверждено):** карьера — центр, жизнь вокруг неё. Плюс
**знакомства открывают карьерные двери** — «нужный человек» даёт доступ к
топ-проектам (AAA), наравне с «сделал хит».

**Игра начинается с детства:** живёшь с родителями, ходишь в школу → в 18 надо
съехать и снять квартиру → начинается карьера. Это осознанный дизайн.

## Архитектура (ЧИСТАЯ, не ломай её)

Три слоя, которые НЕ смешиваются:
```
ДАННЫЕ (state, только факты) → СИСТЕМЫ (чистые функции логики) → UI (React рисует)
```
Папки под `src/`:
- `state/` — initialState.js (стартовое состояние), store.js (хранилище +
  сохранение + нормализация/санитайзер от NaN + dispatch)
- `engine/` — time.js (ход времени, все хуки), economy.js, rng.js, timeline.js
- `systems/life/` — stages.js, family.js, relationships.js, arcs.js, youth.js
- `systems/career/` — actions.js, access.js, offers.js, castings.js
- `systems/meta/` — news.js, email.js, legacy.js
- `systems/social/` — spotlight.js (соцсеть)
- `phone/` — Phone.jsx (оболочка), apps/ (Messages, OpenCall, News, Email, AAA,
  Spotlight, ArcadeGame, registry.js с возрастным гейтингом)
- `ui/` — theme.js, components/ (Button, Card, Stat)
- App.jsx (главный экран, 6-вкладочная навигация), main.jsx

**Правило:** системы не импортируют UI; UI не содержит логики. Одна вещь = одно
место. Если ловишь себя на дублировании — это ошибка архитектуры.

## Как собирать (ВАЖНО)

Собирать ТОЛЬКО через:
```
node build-singlefile.mjs
```
Он делает `dist/game.html` — единый HTML с **обычным inline-скриптом** (НЕ
ES-модулем). Это критично: модульные сборки Vite НЕ запускаются при открытии
файла двойным кликом (file:// блокирует CORS), и у Maxi «мёртвый экран».
Классический inline-скрипт работает везде. Проверяй, что в сборке нет
`type="module"`.

Тесты: файлы `coretest*.mjs` в корне, запускай `node coretestN.mjs`. Это
чистые системные тесты без React. После КАЖДОГО изменения прогоняй их.

Браузерную проверку кликов делай через jsdom (`npm i -D jsdom`), грузи
`dist/game.html` как file:// — так ловятся реальные поломки UI.

## Что УЖЕ СДЕЛАНО (не переделывай, оно работает)

- Каркас, экономика (косты, налог на богатство, долговая спираль)
- Жизненные этапы: детство→тинейджер→съезд→карьера. Время идёт ПО ГОДАМ всю
  юность (с рождения до 18 ~18 кликов), месяцы — только в карьере.
- Карьера: действия (practice с ПОТОЛКОМ навыка от опыта — без ролей max 50,
  растёт через реальные проекты; oddjob, audition, rest, school), офферы
  (масштаб по славе), кастинги (OpenCall, 4 полки)
- **Лестница доступа (сердце игры):** 2 ключа к AAA — хит (рейтинг 85+) ИЛИ
  знакомство с влиятельным человеком (industryWeight 80+, отношения 60+)
- Телефон: 7 приложений. **Детский телефон с 13 лет** — урезанный (Spotlight,
  Bird-игра, Messages, OpenCall только гиги/массовка, Email). Взрослые (News,
  AAA, полный OpenCall) открываются с карьерой.
- **Spotlight** (соцсеть): ищешь одноклассников, держишь связь; кого держал
  близко И кто «выстрелил» → в 22+ становится industry-контактом (3-й путь к AAA)
- **Bird** — мини-игра (flappy), снимает стресс/ментал
- **Семья с рождения** — живые NPC (мама/папа/бабушка/братья): стареют, болеют,
  теряют/находят работу, разводятся, умирают. Действия: провести время,
  попросить денег.
- Арки (6 нарративных с выбором), события юности (5, включая ВЫБОР МЕЧТЫ
  актёр/певец в 10 лет), Legacy + Зал славы
- **Система энергии (AP):** 3 действия на период, обновляются при advance time —
  чинит бесконечный фарм денег/навыка
- 6-вкладочная навигация (Home/Career/People/Style/Legacy/Phone) видна СРАЗУ
- Защита от NaN: normalize() при загрузке + sanitize() на каждый setState
- dispatch ВСЕГДА создаёт новую ссылку {...next} (иначе React не перерисовывает —
  это чинило «кнопки не нажимаются»)
