## Что это технически

React + Vite. Собирается в **один HTML-файл**, который открывается двойным кликом
без сервера и без интернета. В архиве вся папка `src`, точка входа `index.html`,
скрипт сборки и `FEATURES_CHECKLIST.md` — это память проекта, там по шагам записано
всё, что уже сделано и почему.

## Правила, которые нельзя нарушать

1. **Сборка только так:** `node build-singlefile.mjs` → `dist/game.html`.
   Обычный `vite build` НЕ подходит: он даёт `<script type="module">`, а такой файл
   не работает по `file://`. Скрипт сборки инлайнит всё в классический `<script>`.

2. **Архитектура строго в одну сторону:**
   `state/` (данные) → `systems/` (чистая логика) → UI (React только рисует).
   Системы никогда не импортируют UI. В UI нет игровой логики.
   Если между двумя системами возникает круговой импорт — не делай его, положи
   нужное значение в состояние при рождении (так уже сделано с `familyAsk`,
   `familyEstate`).

3. **Состояние меняется только через `dispatch(fn, ...args)`,** и функция обязана
   вернуть НОВУЮ ссылку на состояние. Есть защита `looksLikeState()`: если функция
   вернёт что-то другое (например `{ok, msg}`), сейв будет затёрт. Такой баг уже был.

4. **Ничего темнее фона приложения** (`#150f2c`) в аватарах и графике — тёмное на
   тёмном исчезает. Этот баг ловили дважды.

5. **Никаких `confirm()` и `alert()`** — только модалки внутри игры.

## Как всё устроено

- `src/state/` — начальное состояние и стор (`useSyncExternalStore`, сейв в localStorage)
- `src/engine/` — время (месяцы/годы), экономика, кулдауны, рандом
- `src/systems/life/` — здоровье и болезни, семья, происхождение и деньги семьи,
  отношения (шкала −100…+100 с затуханием), взаимодействия с людьми, вечеринки, внешность
- `src/systems/career/` — кастинги, съёмки, продления сериалов и сиквелы, жанры, обучение
- `src/systems/meta/` — слава и её ступени, новости, почта, наследие
- `src/phone/apps/` — приложения телефона, у каждого свой цвет
- `src/ui/components/` — аватар (SVG из отдельных путей: 16 причёсок, 10 нарядов), кнопки, карточки

## Энергия

3 действия в месяц (`ap`). Разговоры бесплатны, но с кулдауном раз в месяц
на человека и на действие. Всё, что занимает вечер, стоит энергию.

## Что в очереди

1. **Агенты как объект** — сейчас это просто строка с именем. Нужны уровни, свой
   процент (10–15%), характер, возможность быть брошенным. Четыре пути найти
   агента: на вечеринке, через сайт, через съёмки по рекомендации команды,
   и когда после хита приходят сами. Сильного агента нельзя найти ноунеймом.
2. **Квота (`quote`)** — сколько тебе заплатили в прошлый раз. Сам торг уже написан
   (`systems/career/negotiate.js`, со статуса Star). Осталось: квота должна падать,
   когда берёшь дёшево, записываться при любом принятом оффере, а не только после
   выигранного торга, и быть видна игроку.
3. **Офферы как маленькие квесты** — химическая проба, два проекта в одно окно,
   pay-or-play, процент вместо гонорара, франшиза с опционом, замена в последний
   момент, бренд со скандальным прошлым, личный проект режиссёра.
4. **Затухание славы** — сейчас съёмки считаются работой и защищают от забвения.
   Должна защищать премьера, а не процесс. Icon не падает ниже 75.
5. Dating в стиле Tinder, семейное древо вместо списка, цены по городам.
